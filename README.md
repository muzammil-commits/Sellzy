# Pretty Palette — Sellzy E-Commerce Website

A modern, production-grade, responsive e-commerce web platform built on the **Tailwind Sellzy** architecture, customized according to reference specifications.

## 🚀 Running the Project

Open `index.html` directly in any web browser, or launch with any local static server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js (npx serve)
npx serve .
```

All navigation links, styles, scripts, and images use reliable relative paths, ensuring complete compatibility with GitHub Pages, Netlify, Vercel, and local offline browsing.
